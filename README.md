Responsive Design:
- each page links to three style sheets with media queries.
- full.css: uses dimensions 960px and wider, for standard laptops.
- tablet.css: uses dimensions between 481 to 960px, for standard tablets and anything in between phone and laptop.
- phone.css: uses dimensions 480px and less, for standard phones.

Colour Scheme/Gradients:
- utilized a linear gradient for all pages.
- used a basic colour scheme from Adobe Color: #D7C6B4, #ECE7E4, #262626.
- overall colour schemes were kept consistent and simple.
